                  偏差练习处方与复测

                  从已分析乐曲或未过期的多次演奏对比中框选若干连续谱段， 为每段声明必须消除的偏差类别、允许的最大起音/时值误差、最多异常音数， 以及是否禁止待确认；创建时把乐谱指纹、对齐版本与规则整体固化为只读 处方。
                  之后可关联同曲后续录音复测：准入分两条独立校验——来源固化 成员任一过期（对齐版本/音频变化）须先显式重绑；同曲新 录音无需重绑，只要有当前已确认对齐版本即可复测，复测当场固化该 目标对齐版本与音频哈希。谱指纹不同、或目标没有已确认对齐时一律拒绝； 系统按处方谱段重新计算 通过 / 未通过 / 不可判定，逐项给出实际值、阈值、证据音符 与失败原因。历史复测只读，来源或目标之后变化不改写旧结果。

                  从左侧选择一张处方查看时间线与复测差异，或点击上方按钮新建。

                    偏差片段练习谱

                    在单次复盘中，按展开后的整小节（含反复记号展开后的演奏轮次） 框选若干连续片段，为每段设置循环次数、起始速度（BPM）与逐轮增速。 每段必须包含已确认的偏差音；待确认、已排除或低于置信阈值的谱位会 逐位提示并阻止生成。
                    系统从原 MusicXML 提取对应演奏轮次的整小节，保留音高、时值、休止、 拍号、调号与片段内连音，按选定顺序逐轮展开；跨片段连音在边界截断并逐处标记， 绝不留下悬空连音，每轮开头注明原谱坐标与速度。
                    下载的 MusicXML 内嵌来源谱哈希、对齐版本与生成参数；之后来源变化 只把对应版本标记过期、全部历史稿仍可下载。每次成功生成（创建 / 显式重建）都分配独立版本并保留固化清单，任务始终指向明确的 当前版本；可在“版本历史”中查看并下载任一旧版本。重建失败 不新增、不改写任何版本。

                    请先在“单次复盘”页打开一支已分析的录音，再点 ＋ 生成偏差片段练习谱，或从左侧选择已有练习谱。

                    谱面修订迁移

                    选择一条已分析录音及其当前 MusicXML，上传一份修订版单声部 MusicXML。系统对两侧谱面展开反复后，按 （原谱小节、反复轮次、拍位、音高、时值）做确定性匹配，逐谱位区分为 保留 / 移动 / 修改 / 删除 / 新增 / 无法匹配。
                    基于匹配结果，把锚点、对齐快照、未过期对比、处方与练习谱片段逐项标为 可继承 / 需复核 / 失效并说明原因；禁止静默改写历史。 匹配冲突或多声部歧义会阻止提交。确认后创建新的谱面修订记录与 供后续录音使用的复盘入口（旧记录只读、可下载），报告可导出 确定性 JSON。

                    请先在“单次复盘”页打开一支已分析录音，再点 ＋ 谱面修订迁移。
